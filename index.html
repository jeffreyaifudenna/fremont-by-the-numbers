About this site

A data aggregator built by JeffreyAiFudenna using Claude to gather data and write the code

FremontCaByTheNumbers.com does not run its own surveys or measurements. It collects figures that public sources have already published (the City of Fremont, the U.S. Census Bureau, California state agencies, Zillow, Redfin, news reports and others) and puts them in one place.

Claude did the gathering. Claude, Anthropic’s AI model, read each source, recorded the figure with the page it came from and the date it was read, and wrote the code for this site. AI can misread a source, so every number links back to where it came from: click it to open the source in a new tab and check.
